# Practical Machine Learning: Weight Lifting Exercise Prediction

This repository contains the final project for the **Practical Machine Learning** course, part of the Data Science Specialization by Johns Hopkins University on Coursera.

[![License: CC BY-NC-ND 4.0](https://img.shields.io/badge/License-CC%20BY--NC--ND%204.0-lightgrey.svg)](https://creativecommons.org/licenses/by-nc-nd/4.0/)

## Project Overview
The goal of this project is to predict the manner in which participants performed barbell lifts. This is a classification problem where the outcome is the `classe` variable, categorized into five different ways (A, B, C, D, E).

## Repository Contents
* **PML_Project.html**: The compiled analysis report in HTML format.
* **PML_Project.Rmd**: The original R Markdown source code.
* **README.md**: This documentation file.

## Key Findings
* **Algorithm Used:** Random Forest
* **Cross-Validation:** 70/30 Training/Validation split
* **Accuracy:** 99.64%
* **Out-of-Sample Error:** 0.36%

## Data Source
The data for this project comes from the Weight Lifting Exercise Dataset provided by:
*Groupware@LES: http://groupware.les.inf.puc-rio.br/har*
